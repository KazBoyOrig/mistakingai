# Обучи ошибающегося ИИ

Тренажёр понимания процентов: ИИ играет ученика и специально показывает решение с ошибкой. Пользователь находит первый неверный шаг, объясняет причину и решает похожую задачу.

**Этап 1 — запускаемый каркас с одной проверенной демонстрационной задачей.** Это ещё не полный MVP на 15 задач. В интерфейсе явно написано: «ИИ специально ошибается. Найди первый неверный шаг».

## Что работает

- Задача о скидке и последующей наценке, четыре шага ошибочного решения.
- Выбор первого неверного шага и поле объяснения своими словами.
- Проверка шага серверным кодом, эталонный разбор после отправки формы.
- Похожая задача и проверка числового ответа серверным кодом.
- Сохранение до 100 завершённых попыток в `localStorage`, счётчик попыток после перезагрузки.
- Русский адаптивный интерфейс, состояния загрузки и ошибок, управление с клавиатуры.

**Проверки объяснения языковой моделью на этом этапе нет.** Текст объяснения обязателен и сохраняется локально, но его смысл не получает оценку. После отправки показывается эталон для самостоятельного сравнения. Даже неверное по смыслу объяснение откроет разбор; это прямо обозначено как деморежим.

## Запуск

Требуется Node.js **22.12 или новее**, рекомендуется Node.js 24 LTS, и npm.

```bash
git clone https://github.com/KazBoyOrig/mistakingai.git
cd mistakingai
npm ci
npm run dev
```

Открыть **http://127.0.0.1:5173**. Одна команда запускает Vite и небольшой сервер Node.js на `127.0.0.1:3001`; запросы `/api` идут через прокси Vite. Для этой демонстрации API-ключ и `.env` не нужны.

В Windows PowerShell, если политика выполнения блокирует `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd run dev`.

## Проверки и запуск сборки

```bash
npm run check
npm start
```

`check` запускает тесты эталона, числового парсера и HTTP API, проверяет TypeScript и собирает интерфейс в `dist/`. После сборки `npm start` отдаёт и интерфейс, и API на **http://127.0.0.1:3001**. Остановка — Ctrl+C.

Другие команды: `npm test`, `npm run typecheck`, `npm run build`, `npm run dev:client`, `npm run dev:server`.

Необязательно скопируйте `.env.example` в `.env`, чтобы изменить `HOST` и `PORT`. Прокси Vite настроен на порт 3001: при изменении порта для разработки поменяйте также `vite.config.ts`. Секреты в `.env` не попадают в Git.

## Как проверить вручную

1. Выберите **шаг 3** и напишите: «Наценка считается от 1600, а не от 2000: после скидки база изменилась».
2. Нажмите «Проверить шаг и открыть разбор»: правильный итог — **1920 ₽**.
3. В похожей задаче введите **990** или **990,00**. Попытка должна сохраниться.
4. Обновите страницу: счётчик попыток сохранится. Текущая незавершённая форма начинает новую тренировку.
5. Попробуйте шаг 2 или 4, ответ 1000, пустое объяснение, формулу вместо числа. Интерфейс должен объяснить ошибку или не разрешить отправку.

Прогресс относится к конкретному браузеру и адресу: `localhost`, `127.0.0.1` и разные порты имеют отдельные хранилища. Если хранилище заблокировано, результат показывается, а приложение сообщает, что он не сохранён. Очистка данных сайта удаляет прогресс. Неверный числовой ответ тоже завершает и сохраняет попытку; повторить можно кнопкой «Пройти ещё раз».

## Структура

```text
src/                  React, интерфейс, API-клиент и локальный прогресс
shared/types.ts       Контракты клиента и сервера
server/exercises.ts   Демозадача, проверенный эталон, будущая рубрика ИИ
server/app.ts         HTTP API и отдача готовой сборки
server/index.ts       Запуск Node.js сервера
server/app.test.ts    Проверки математики и HTTP API
SPEC.md               Описание полного MVP и этапов
```

API: `GET /api/health`, `GET /api/exercises/demo`, `POST /api/review` (`exerciseId`, `selectedStep`, `explanation`), `POST /api/practice` (`exerciseId`, `answer`). Эталоны не входят в исходный ответ API задачи и не импортируются клиентом. Решение ИИ заранее подготовлено; оно не генерируется на лету.
